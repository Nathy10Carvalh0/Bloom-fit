# Bloom Fit 🌿

Aplicativo pessoal de alimentação, exercícios, balanço energético, evolução corporal e desafio de 75 dias. HTML, CSS e JavaScript, sem backend e sem integração com Apple Saúde.

## Publicar no GitHub Pages
1. Envie todos os arquivos deste diretório para a raiz do seu repositório GitHub.
2. Em **Settings → Pages**, escolha **Deploy from a branch**, branch **main**, pasta **/(root)** e salve.
3. Abra a URL que o GitHub mostrar em Pages.
4. No Safari do iPhone: **Compartilhar → Adicionar à Tela de Início**.

## Limitações importantes
- Os dados ficam no `localStorage` do navegador e **não são sincronizados**. Faça backups em **Evolução → Exportar backup JSON**.
- GitHub Pages publica a interface na web. Não armazene dados pessoais no repositório.
- Cálculos nutricionais e de exercícios são estimativas; confirme alimentos com rótulos e tabelas confiáveis.
- O gasto total usa metabolismo basal estimado, fator de atividade e exercício adicional. Configure o fator para não contar atividades duas vezes.
- Não há login, IA, fotos armazenadas nem conexão automática com sensores. A foto diária é um checklist.
- Para privacidade, evite compartilhar o aparelho e use os recursos de proteção do iPhone.
